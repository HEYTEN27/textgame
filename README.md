# Текстовые приключения

Консольная текстовая игра на Python для Windows 10 (работает и в Linux/macOS).
Движок исполняет сценарии из JSON-файлов в `data/scenarios/` и ничего не знает о конкретных историях.

Десятый сценарий — самостоятельная замена исходной завязки «Протокол Стирание» (см. DECISIONS.md).

## Скачать и играть (Windows 10/11)

1. Откройте страницу [Releases](https://github.com/HEYTEN27/textgame/releases/latest) и скачайте `TextAdventure.exe`.
2. Положите его в любую папку (например, на рабочий стол) и запустите двойным щелчком.
3. Если Windows покажет «Система Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае»:
   exe не подписан цифровой подписью, это обычное предупреждение для самодельных программ.

Сохранения, автосохранение, настройки, статистика и открытые концовки хранятся в папке `saves` рядом с exe.
Exe собирается автоматически на Windows при каждом изменении в `main` (GitHub Actions, `.github/workflows/build-windows.yml`):
перед сборкой прогоняются тесты, валидатор и бот, после — пробный запуск exe.

## Запуск из исходников

```
python main.py
```

Нужен Python 3.11+. `colorama` необязательна: без неё не будет цветов только в старых консолях Windows.

## Сборка exe

Запустите `build.bat` на Windows 10. Он создаст venv, поставит зависимости, прогонит тесты, валидатор и бота
(при любой ошибке сборка прерывается) и соберёт `dist\TextAdventure.exe` с папкой `data` внутри.
Сохранения создаются в `saves\` рядом с exe.

## Что есть в игре

- 10 историй в разных жанрах: 457 сцен, больше 1100 вариантов действий, около 52 000 слов текста.
  У каждой истории 6–8 концовок, включая секретные, и побочные ветки со своими персонажами и находками, которые меняют финал.
- Фоновая музыка для каждой истории, меню и концовок (Kevin MacLeod, CC BY 4.0, см. [CREDITS.md](CREDITS.md)).
  Громкость и выключение — в «Настройках». На Windows музыка играет через встроенный MCI,
  на Linux/macOS — через `ffplay`, `mpg123` или `afplay`, если они установлены.
- Автосохранение после каждого действия: «Продолжить» в главном меню возвращает в последнюю игру.
- Команда `отменить` — откат последнего действия (до 30 шагов).
- Команда `подсказка` — что ещё не изведано в текущей сцене (не раскрывая решений).
- Очистка экрана между сценами и строка состояния со статами сверху (отключается в настройках).
- Галерея концовок с типами неоткрытых концовок, процент прохождения и статистика: время в игре, число историй.
- Экран итогов после концовки: ходы, время, сколько концовок истории открыто.
- Раздел «Об игре и авторы».

## Команды

| Команда | Действие |
|---|---|
| `<номер>` | выбрать вариант |
| `и`, `инвентарь` | инвентарь |
| `осмотреть <предмет или деталь сцены>` | подробное описание (иногда секрет) |
| `осмотреться` | описать сцену заново |
| `использовать <предмет>` или `использовать <номер>` | применить предмет здесь |
| `статус` | статы и ресурсы |
| `отменить` | откатить последнее действие (до 30 шагов) |
| `подсказка` | что ещё не изведано в этой сцене |
| `журнал` | хроника событий |
| `сохранить` / `загрузить` | 3 слота |
| `помощь` | справка |
| `выход` | в главное меню (с подтверждением) |

Предметы ищутся по началу слова, алиасам и с одной опечаткой: «ключ», «ключа», «латунного ключа», «клюс».
Enter во время печати допечатывает текст. Скорость текста и цвета меняются в «Настройках».

## Инструменты

```
python -m unittest discover -s tests     # unit-тесты движка
python tools/validate.py [-v] [файл]     # граф сюжета и требования к контенту
python tools/autoplay.py [-n 1000] [--seed 1] [id]   # бот-тестировщик
```

Валидатор проверяет: переходы ведут на существующие сцены; нет недостижимых сцен и концовок; в каждой сцене
есть безусловный выход; из каждой сцены достижима концовка; все предметы описаны и имеют применение;
флаги, которые проверяются, где-то ставятся; квоты (35+ сцен, 4+ концовки нужных типов, 5+ предметов,
3+ значимые развилки, 2+ проверки, персонаж, секрет, 2–4 стата с особой концовкой при нуле); нет заглушек.

Бот 1000 раз проходит каждый сценарий: выбирает варианты (с лёгким уклоном в неизведанное), использует и
осматривает предметы, вводит мусор, решает головоломки, сохраняется и загружается посреди игры.
Ошибка — падение, сцена без вариантов, больше 1500 шагов или недостигнутая концовка.

## Как добавить свой сценарий

Положите `имя.json` в `data/scenarios/`. Файлы на `_` скрыты из меню (видны при `TA_DEBUG=1`).
Минимальный полный пример всех механик — `data/scenarios/_test.json`.

```json
{
  "id": "myid", "title": "Название", "genre": "жанр", "teaser": "Тизер", "order": 11,
  "stats": {
    "здоровье": {"value": 10, "max": 10, "zero_ending": "end_dead"},
    "доверие": {"value": 5, "max": 10, "hidden": true, "zero_ending": "end_x"},
    "патроны": {"value": 4, "max": 8, "kind": "resource"},
    "время":  {"value": 0, "max": 8, "kind": "resource", "offset": 22, "mod": 24, "format": "{v2}:00"}
  },
  "start_items": ["key"],
  "characters": {"npc": {"name": "Имя", "description": "Характер и мотивация"}},
  "items": {
    "key": {"name": "латунный ключ", "aliases": ["ключ"], "description": "...",
            "examine_secret": {"if": {"flag": "f"}, "text": "...", "effects": []},
            "use": {"if": null, "text": "...", "effects": [], "goto": null, "consume": false, "once": false, "else_text": "..."}}
  },
  "timers": [{"id": "t", "every": 5, "max": 4, "if": null, "effects": [], "texts": ["..."], "goto": "node", "style": "danger"}],
  "start": "n1",
  "nodes": {
    "n1": {
      "text": [{"if": {"revisit": true}, "text": "Снова здесь"}, {"text": "Первый раз"}],
      "extra": [{"if": {"has_item": "key"}, "text": "Дополнительный абзац"}],
      "on_first_enter": [], "on_enter": [],
      "examine": {"окно": {"aliases": ["стекло"], "text": "...", "effects": [], "goto": null, "once": false}},
      "item_uses": {"key": {"text": "...", "effects": [], "goto": "n2", "if": null, "once": false, "else_text": "..."}},
      "choices": [
        {"text": "Пойти", "goto": "n2"},
        {"text": "Поговорить", "once": true, "result": "Ответ NPC", "effects": [{"set_flag": "f"}]},
        {"text": "Прыгнуть", "check": {"stat": "здоровье", "dc": 12, "bonus": [{"if": {"has_item": "key"}, "value": 2}]},
         "success": "n2", "fail": "n3", "success_text": "...", "fail_effects": []}
      ]
    },
    "r": {"router": [{"if": {"flag": "f"}, "goto": "end_good"}, {"goto": "end_bad"}]},
    "pz": {"text": "Замок", "input": {"prompt": "Пароль", "answers": [{"match": ["слово"], "goto": "n2"}],
           "attempts": 3, "wrong_text": ["Нет"], "on_fail": "n1"}, "choices": [{"text": "Уйти", "goto": "n1"}]}
  },
  "endings": {"end_good": {"title": "...", "type": "good", "text": "...", "extra": [], "secret": false}}
}
```

**Типы концовок:** `good`, `bad`, `strange`, `secret`, `death`, `defeat`, `neutral`.

**Условия** (словарь — все ключи сразу; список — И): `has_item`, `not_item`, `flag`, `not_flag`, `any_flag`,
`stat_gte`, `stat_lte`, `stat_gt`, `stat_lt` (`{"стат": N}`), `visited`, `not_visited`, `revisit` (уже бывал в текущей сцене),
`turns_gte`, `turns_lte`, `timer_gte` (`{"таймер": N}` — сколько раз сработал), `any`, `all`, `not`.

**Эффекты:** `give_item`, `take_item`, `set_flag`, `clear_flag`, `stat` (`{"стат": ±N}`), `stat_set`, `journal`,
`text`, `danger`, `{"if": усл, "then": [...], "else": [...]}`, `random` (`[{"weight": 1, "effects": [...], "text": "..."}]`).

**Тексты:** строка или список вариантов `[{"if": ..., "text": ...}, ...]` (берётся первый подходящий).
Подстановки: `{stat:имя}`, `{item:id}`, `{turns}`, `{rand:а|б|в}`. Разметка: `[предмет]` — жёлтым, `<опасность>` — красным.

**Проверка навыка:** d20 + модификатор `(стат − 5) // 2` + бонусы против `dc`; натуральные 20 и 1 — автоуспех/автопровал.
Игрок видит шансы словами («шансы невелики» … «почти наверняка»).

**Ход** — любой выбор варианта, применение предмета или ответ на головоломку; таймеры считают ходы.
Если стат с `zero_ending` упал до 0, игра сразу переходит в эту концовку.
